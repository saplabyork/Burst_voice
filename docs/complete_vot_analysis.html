Setup and data preparation

ons_poa is coded once here as a factor with levels/labels c("p", "t", "k"), and coda_vc once as a factor with levels c(0, 1). Every plot, model, and prediction grid in the rest of this document inherits this coding and reference level (/p/), rather than each section re-deriving place-of-articulation labels independently.

data <- data %>%
  mutate(
    ons_poa = factor(ons_poa, levels = c(1, 2, 3), labels = c("p", "t", "k")),
    coda_vc = factor(coda_vc, levels = c(0, 1)),
    # Convert VOT and vowel duration from seconds (as stored in the
    # raw CSV) to milliseconds. This matters beyond readability: the
    # informed priors specified later (e.g., normal(30, 10) for the
    # /p/ intercept) were written assuming a millisecond-scale
    # outcome, but were previously being applied to vot/vdur while
    # still in seconds -- a units mismatch that made those priors
    # far less informative than intended (a prior centered at "30"
    # is only meaningfully informative if the outcome is actually on
    # a scale where 30 is a plausible value). Converting here keeps
    # the data and the priors on the same scale throughout.
    vot  = vot * 1000,
    vdur = vdur * 1000,
    vot_ratio = vot / vdur,   # unitless; unaffected by the ms conversion
    CVdur = vot + vdur
  )

Basic descriptive statistics for onset VOT, vowel duration, the VOT/vowel-duration ratio, and combined CV duration, broken down by place of articulation and coda voicing (the two manipulated factors) and reported alongside the overall totals. sd is the standard deviation of individual tokens within each cell (not a standard error), so these numbers reflect the same raw variability visualized in the boxplots and ridge plots below, before any model-based smoothing.

Maximal random effects structure (primary model)

Because onset place of articulation and coda voicing are both within-subject manipulations, a random-intercept-only model assumes every participant shows the same coda-voicing effect (and the same place-of-articulation effects), differing only in their overall baseline VOT. Following Barr, Levy, Scheepers & Tily (2013), our primary model instead includes by-subject random slopes for place of articulation, coda voicing, and their interaction, plus the full correlation structure among all random effects, from the outset. This guards against anti-conservative (too-narrow) intervals for the fixed effects if speakers actually differ in the size of the coda-voicing effect, not just their baseline VOT. We fit this maximal structure first; a reduced structure is only considered as a fallback if the maximal model fails to converge (see below).

We fit the maximal structure twice: once with brms’ default weakly informative priors, and once with the literature-informed priors used throughout this document, so that the same default-vs-informed comparison we would otherwise have run on an intercept-only model is instead run on the model we actually report. The informed priors below encode only what the literature actually supports well: the relative place-of-articulation ordering and approximate contrast magnitudes (/p/ \(<\) /t/ \(<\) /k/), and non-negativity of the absolute /p/ baseline. They deliberately do not encode a specific absolute baseline value for /p/, since English VOT for a given place of articulation varies considerably across speech styles and elicitation methods, and we have no single well-calibrated value to anchor it to.

maximal_priors <- c(
  # Intercept: no informative location prior. English /p/ VOT varies
  # considerably across speech styles, elicitation methods, and
  # corpora (careful/citation-form speech tends to run longer than
  # casual speech), so we don't have a single well-calibrated
  # absolute value to anchor the baseline to -- unlike the POA
  # *contrasts* below, where the ordering and approximate relative
  # magnitude are well established across studies regardless of
  # absolute baseline. We only constrain the intercept to be
  # non-negative (VOT cannot be negative for voiceless stops in this
  # coding), via a wide, effectively flat prior over the plausible
  # range combined with a lower bound at zero.
  prior(normal(0, 100), class = Intercept, lb = 0),

  # Strongly informed: established literature on the *relative*
  # place-of-articulation ordering and approximate contrast
  # magnitude (more posterior places of articulation associated with
  # longer VOT), independent of the absolute baseline
  prior(normal(15, 8),  class = b, coef = ons_poat),
  prior(normal(30, 12), class = b, coef = ons_poak),

  # Weakly informed / regularizing: the focal, untested hypothesis
  prior(normal(0, 20),  class = b, coef = "coda_vc1"),
  prior(normal(0, 15),  class = b, coef = "ons_poat:coda_vc1"),
  prior(normal(0, 15),  class = b, coef = "ons_poak:coda_vc1"),

  # Random-effect SDs (applies to intercept + all random slopes)
  prior(normal(0, 20), class = sd),

  # Residual SD
  prior(normal(0, 25), class = sigma),

  # Correlation matrix among random effects: lkj(2) mildly shrinks
  # correlations toward zero relative to the lkj(1) (uniform) default,
  # which helps stabilize estimation with only 20 subjects
  prior(lkj(2), class = cor)
)

If the maximal model does not converge cleanly

Both maximal models above converged cleanly in our run (zero divergent transitions, \(\hat{R} \leq 1.00\) throughout), so no simplification was necessary. If a future re-fit (e.g., after adding trials, changing priors, or modifying the formula) shows divergent transitions, elevated \(\hat{R}\), or very low ESS on the random-effect correlations, simplify in this order before abandoning the random-slopes structure entirely:

# (equivalent to lme4's `||` syntax)

Does the VOT/vowel-duration ratio differ by coda voicing?

If onset VOT and vowel duration both lengthen together under a shared word-level timing mechanism, the ratio of VOT to vowel duration (vot_ratio, computed in the data-preparation step above) might stay roughly constant across coda-voicing contexts even though the raw VOT differs. Testing whether vot_ratio itself varies by coda voicing is therefore a useful check: a credible coda-voicing effect on the ratio would suggest VOT and vowel duration are not simply scaling together proportionally, while a ratio effect indistinguishable from zero would be consistent with proportional scaling. For consistency with the primary VOT model above, this is fit with the same maximal random-effects structure (by-subject random slopes for place of articulation, coda voicing, and their interaction, plus their correlations).

# Maximal random-effects structure, matching the main VOT model above
# for consistency. We do NOT reuse maximal_priors here: those priors
# (e.g., the POA contrast priors of normal(15,8)/normal(30,12) ms,
# the coda-voicing prior of normal(0,20) ms) are scaled for a
# millisecond-scale outcome, but vot_ratio is a unitless quantity
# with a very different scale (~0.8, roughly 0-1.5 range). Applying
# ms-scale priors here would be exactly the kind of units mismatch
# we corrected earlier for vot/vdur. brms' default priors are scaled
# automatically from the data, so we rely on those instead, with the
# same sampler settings (iterations, warmup, adapt_delta) as the main
# maximal model for consistency and comparable convergence behavior.
bayes_model_ratio <- brm(

make_ridge_plot <- function(model, plot_title = "") {

  newdata <- expand_grid(
    ons_poa = c("p", "t", "k"),
    coda_vc = c("0", "1")
  )
  newdata$ons_poa <- factor(newdata$ons_poa, levels = levels(data_mod$ons_poa))
  newdata$coda_vc <- factor(newdata$coda_vc, levels = levels(data_mod$coda_vc))

  preds <- posterior_epred(model, newdata = newdata,
                            allow_new_levels = TRUE, re_formula = NA)

  pred_summary <- newdata %>%
    mutate(
      estimate = apply(preds, 2, mean),
      lower    = apply(preds, 2, quantile, 0.025),
      upper    = apply(preds, 2, quantile, 0.975)
    )

  pred_summary$poa_coda <- factor(
    interaction(pred_summary$coda_vc, pred_summary$ons_poa),
    levels = c("0.p", "1.p", "0.t", "1.t", "0.k", "1.k")
  )

  ggplot() +
    geom_density_ridges(
      data = data_mod,
      aes(x = vot, y = poa_coda, fill = poa_coda, linetype = coda_vc_factor),
      alpha = 0.8, scale = 0.8
    ) +
    scale_linetype_manual(
      name = "Coda voicing",
      values = c("Voiceless" = "dashed", "Voiced" = "solid")
    ) +
    geom_point(
      data = pred_summary,
      aes(x = estimate, y = poa_coda, color = poa_coda),
      size = 3, position = position_nudge(y = 0.2)
    ) +
    geom_errorbarh(
      data = pred_summary,
      aes(x = estimate, y = poa_coda, xmin = lower, xmax = upper, color = poa_coda),
      height = 0.1, position = position_nudge(y = 0.2)
    ) +
    scale_fill_manual(values = c(
      "0.p" = "#B71C1C", "1.p" = "#FFCDD2",
      "0.t" = "#1B5E20", "1.t" = "#C8E6C9",
      "0.k" = "#0D47A1", "1.k" = "#BBDEFB"
    )) +
    scale_color_manual(values = c(
      "0.p" = "#67000D", "1.p" = "#A50F15",
      "0.t" = "#00441B", "1.t" = "#006D2C",
      "0.k" = "#08306B", "1.k" = "#08519C"
    )) +
    annotate("text", x = 10, y = 1.5, label = "/p/", hjust = 1.2, vjust = 0.5,
             size = 4, fontface = "bold") +
    annotate("text", x = 10, y = 3.5, label = "/t/", hjust = 1.2, vjust = 0.5,
             size = 4, fontface = "bold") +
    annotate("text", x = 10, y = 5.5, label = "/k/", hjust = 1.2, vjust = 0.5,
             size = 4, fontface = "bold") +
    labs(x = "VOT (ms)", y = "", title = plot_title) +
    xlim(0, 200) +
    coord_cartesian(ylim = c(0.5, 6.5)) +
    theme_minimal() +
    guides(fill = "none", color = "none",
           linetype = guide_legend(title = "Coda voicing", direction = "vertical")) +
    theme(
      axis.text.y = element_blank(),
      axis.ticks.y = element_blank(),
      legend.position = c(0.85, 0.20),
      legend.background = element_rect(fill = "white", color = "black", linewidth = 0.3),
      panel.grid.major.y = element_blank(),
      panel.grid.minor.y = element_blank(),
      plot.margin = margin(t = 15, r = 5, b = 0, l = 5, unit = "pt")
    ) +
    scale_y_discrete(expand = expansion(mult = c(0.05, 0.15)))
}
